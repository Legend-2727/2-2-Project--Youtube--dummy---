# YouTube Dummy

## Overview
YouTube Dummy is a feature-rich video-sharing platform that replicates the core functionalities of YouTube. It allows users to watch, like, dislike, comment on videos, and receive personalized recommendations. The platform also includes an ad system where companies can upload advertisements and track their performance.

## Features

### General Users (Not Logged In)
- Can browse and watch videos without an account.

### Registered Users
- Can log in to like, dislike, and comment on videos.
- Receive video suggestions based on an implemented recommendation algorithm.
- **Access recent watch history, liked videos, and watch later list.**
- Report inappropriate videos.

### Advertisers (Companies)
- Can log in and upload advertisements.
- Track the number of times their ads are shown.
- Pay based on ad views.

### Ad Management
- **Ads are displayed at definite intervals within a video.**
- Advertisers can monitor ad performance and view analytics.

### Admin Panel
- Monitors the platform and manages content.
- Reviews reported videos and can delete them if necessary.
- Sends notifications and warnings to users.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js with Express.js
- **Database:** MySQL for storing user data, video metadata, comments, likes/dislikes, ads, and reports.
